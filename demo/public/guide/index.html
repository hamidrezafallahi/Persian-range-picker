React Jalali Date Picker & Persian Range Picker

A lightweight Jalali (Persian / Shamsi) and Gregorian calendar library for React: single DatePicker, date range picker with compare, keyboard Mask, and TimePicker.

Install

npm i react-persian-range-picker

Peer dependencies: react and react-dom (^17 / ^18 / ^19).

Quick start — Jalali DatePicker

import { DatePicker, RangePicker, Mask, TimePicker } from 'react-persian-range-picker';

<DatePicker
  calendarType="jalali"
  exportType="timeStamp"
  showMask
  allowClear
  onChange={(v) => console.log(v)}
/>

What you get

  • DatePicker — Persian/Jalali single date (+ optional mask & time)
  • RangePicker — Shamsi date range + optional compare (ERP/analytics)
  • Mask — type YYYY/MM/DD with segment focus
  • TimePicker — hour / minute / second
  • Calendar — embeddable grid
