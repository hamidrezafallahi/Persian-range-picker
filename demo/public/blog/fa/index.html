از انتخاب تاریخ ساده تا مقایسه بازه در ERP با react-persian-range-picker

بیشتر Date Pickerها فقط یک تاریخ یا یک بازه می‌گیرند. در ERP و داشبورد، نیاز واقعی اغلب مقایسه دو بازه و حرکت هم‌زمان آن‌هاست — روی تقویم شمسی. کتابخانه react-persian-range-picker برای همین سناریو ساخته شده است.

طیف نیازمندی‌ها

سطحنیازکامپوننت
۱یک تاریخDatePicker
۲تایپ کیبوردیMask
۳ساعتTimePicker
۴یک بازهRangePicker
۵مقایسه دو بازهshowComparison
۶ناوبری هم‌زمانisShowNavigationButton

نصب

npm i react-persian-range-picker

نمونه Range + Compare

import { RangePicker } from 'react-persian-range-picker';

<RangePicker
  calendarType="jalali"
  exportType="timeStamp"
  showComparison
  isShowNavigationButton
  onChange={(e) => console.log(e.Data?.date)}
/>

  • جابه‌جایی هم‌زمان بازه اصلی و مقایسه

  • پشتیبانی میلادی، ماسک کیبوردی، TypeScript، React ۱۷ تا ۱۹
