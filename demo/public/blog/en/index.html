From Simple Date Picking to ERP Range Comparison in React (Jalali + Gregorian)

Most React date libraries answer: “Which day did the user pick?” Enterprise dashboards ask: “Compare this period to another — then move both ranges together.” That is the gap react-persian-range-picker is built for.

Install

npm i react-persian-range-picker

Range + compare example

import { RangePicker } from 'react-persian-range-picker';

<RangePicker
  calendarType="jalali"
  exportType="timeStamp"
  showComparison
  isShowNavigationButton
  onChange={(e) => console.log(e.Data?.date)}
/>

What makes it different?

  • Enterprise-style range comparison
  • Synced primary + compare period navigation
  • Jalali-native engine via jalaali-js (leap-year aware)
  • Gregorian mode via calendarType="gregorian"
  • Keyboard Mask, TimePicker, TypeScript, React 17–19

FAQ

Does it handle Jalali leap years? Yes — via jalaali-js.

Jalali only? No. Use calendarType="gregorian".

React 19? Yes.
